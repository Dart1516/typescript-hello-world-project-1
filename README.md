# Overview

With this project I'm traying to learn about how to program in typescript. This will open the door for new technologies. 

I will create a command-line vocabulary learning tool for English. It works like a dictionary, but instead of showing only the definition of a word, it also expands two related words found inside that definition to give better context. 

I chose this idea because people like me who are learning English often look up a word and still cannot fully understand its definition, since the definition itself contains unfamiliar words.
 


This allows us to create larger and safer projects, which would otherwise be a nightmare to maintain.
